# Database-Carburant-SAE-S2.04 - Analyse des stations-service et des prix des
carburants à partir de données ouvertes

Ce projet vise à démontrer la capacité à concevoir, structurer et exploiter une base de données à partir
de données réelles, en mobilisant des traitements variés et adaptés à des besoins d’analyse concrets.

##  Trinômes
* **Anass Fathi**
* **Hamza El Boubakri**
* **Wassil Seghirouali**

##  Objectifs

- centraliser les informations relatives aux stations-service ;
- gérer les différents types de carburants proposés ;
- suivre l’évolution des prix dans le temps ;
- intégrer les informations d’ouverture et de disponibilité ;
- analyser les écarts de prix et les conditions d’accès ;
- produire des indicateurs utiles à la prise de décision


##  Technologies utilisées

- **Modélisation** : AGL : PGmodeler .
- **SGBD** : PostgreSQL / MySQL.
- **Langage** : SQL.
- Python pour la collecte et le traitement des données ;
- Grafana pour la visualisation des données.
